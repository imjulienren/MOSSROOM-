# Mossroom Studio 使用说明

在现代浏览器中打开 `dist/index.html`，或在 macOS 双击「打开 Mossroom Studio.command」。

1. 导入或拖入已经制作好的音效、音乐。在资料库中切换文件。
2. 拖动波形选择片段，或在剪辑选区填写起止时间。拖动波形下方的播放进度条可以在选区内跳转。打开循环检查 BGM 接缝。
3. 使用音色、力度和混响处理声音，在输出模块设置增益、淡入淡出和限制器。悬停或聚焦标题旁的问号可查看参数说明。点击「原音对比」切换试听。
4. 点击「导出音频」，选择当前选区或完整音频。WAV 可选 16 / 24 bit，MP3 可选 128 / 192 / 320 kbps。两者都可选择采样率和单声道。

局部拉伸支持原时长的 25% 至 400%，处理时保持音高。按住 Option 或 Alt 拖动选区右边缘可以快速拉伸。需要保留混响尾音时，可在音频结尾插入空白并将其包含在导出范围内。

输入格式取决于浏览器解码能力，通常支持 MP3、WAV、M4A、FLAC 等。多于双声道的输入会混合为立体声。单文件上限 100 MB，已解码资料库内存上限 384 MB。编辑保存在当前页面内存中，刷新或关闭页面前请先导出。

更多快捷操作见工作台右上角的键盘图标。
