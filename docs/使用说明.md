# Mossroom Studio 使用说明

在现代浏览器中打开已发布的 Mossroom Studio 网页。

1. 导入或拖入已经制作好的音效、音乐。在资料库中切换文件。
2. 拖动波形选择片段，或在剪辑选区填写起止时间。拖动波形下方的播放进度条可以在选区内跳转。打开循环检查 BGM 接缝。
3. 使用音色、力度和混响处理声音，在输出模块设置增益、淡入淡出和限制器。悬停或聚焦标题旁的问号可查看参数说明。点击「原音对比」切换试听。
4. 点击「导出音频」，选择当前选区或完整音频。WAV 可选 16 / 24 bit，MP3 可选 128 / 192 / 320 kbps。两者都可选择采样率和单声道。

局部拉伸支持原时长的 25% 至 400%，处理时保持音高。点击「拉伸选区」可输入目标时长。需要保留混响尾音时，可在音频结尾插入空白并将其包含在导出范围内。

输入格式取决于浏览器解码能力，通常支持 MP3、WAV、M4A、FLAC 等。多于双声道的输入会混合为立体声。单文件上限 100 MB，已解码资料库内存上限 384 MB。编辑保存在当前页面内存中，刷新或关闭页面前请先导出。


## 视频剪辑

切换到「视频剪辑」，可一次拖入或选择多个视频。点击左侧资料库里的文件来切换，每个视频的选区和播放位置都会保留到页面刷新。拖动缩略图时间轴上的两个手柄设置起止点，也可以输入具体时间。下方进度条在选区内定位，播放到结束点会自动暂停。

暂停到想要的画面后，点击播放控件旁的「截图」。右侧会显示当前视频的截图，窄屏上显示在编辑区下方。鼠标停在缩略图上半秒可查看大图，点击则下载原画面尺寸的 PNG。刷新或关闭页面前，请下载要保留的截图。

点「导出视频」，可将选区导出为保留声音的 MP4 或静音循环的 GIF。GIF 默认长边 480 px、12 帧/秒，可选择 320、480、720 px 和 8、12、15、20、25 帧/秒。导出窗口在生成前显示预计大小，完成后显示下载文件的实际大小。文件全程在浏览器本地处理，可用格式取决于浏览器的解码和编码能力。
