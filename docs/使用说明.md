# Mossroom Studio

棕色与绿色的复古像素调音室。双击「打开 Mossroom Studio.command」，或直接在 Safari、Chrome 中打开 dist/index.html，即可离线使用。

1. 点击「导入音频」或拖入文件。可导入多个文件，在资料库切换。
2. 在波形上拖动选择片段，拖动两端手柄微调；也可以输入开始、结束时间，例如 `00:03.250` 或 `3.25`。
3. 点击播放试听选区，开启循环可反复播放。试听速度支持 0.5× 至 2×，会同时改变音调，仅影响试听。
4. 用调音台处理声音。修改参数会自动开启对应模块，也可独立关闭模块。提供人声清晰、温暖录音、播客与音乐预设，选区和调音均支持撤销与重做。
5. 点击「拉伸选区」，拖动长度滑块或输入目标时长。应用后保持音高，后续内容自动移动。也可按住 Option（Windows 为 Alt）拖动右侧手柄直接拉伸。支持原长度的 25% 至 400%，源片段与目标时长至少为 0.020 秒；大幅拉伸可能改变音色。
6. 点击「插入空白」，指定位置和时长，或定位到光标、选区开始、选区结束。支持插入 0.001 至 600 秒静音。
7. 点击「导出音频」，选择完整音频或当前选区，再设置名称、采样率、16/24 bit 位深和声道，保存 WAV。时间编辑后默认导出完整音频。

调音功能：

- 低切与高切，滤除低频隆隆声及过高频率；屏幕显示滤波和 EQ 的合成响应。
- 三段 EQ，低频与高频搁架、中频峰值均衡，中频中心频率可调。
- 压缩器，含阈值、压缩比、启动、释放与补偿增益。
- 噪声门，减少低于阈值的底噪，释放时间可调。它不移除说话时混在声音中的噪声。
- 混响、反馈延迟，支持调整混响时长、延迟间隔与反馈。
- 声像、立体声宽度、单声道合并与峰值限制器。
- 输出增益、淡入淡出、峰值标准化至 −1 dB。
- 双声道输出电平、PEAK、RMS、最大动态增益衰减 GR，以及可清除的削波记录。

「原音对比」会试听未经调音、增益与淡入淡出处理的当前选区；已做的拉伸和空白编辑仍保留。「监听音量」只控制扬声器试听大小。原音对比、监听音量、试听速度均不影响导出。

所有调音处理应用于所选试听或导出范围，效果状态在范围开头重置。混响与延迟不自动延长时间线；需要保留尾音时，先在音频结尾插入足够空白，再选择完整范围导出。峰值限制器限制采样峰值，不是过采样真峰值或响度标准处理器。

音频在浏览器内存中处理，不上传服务器。原始文件不会被改写，关闭或刷新页面后需重新导入。单个源文件上限 100 MB，资料库已解码音频内存上限 384 MB。较长音频或多个效果一起处理时需要等待。

输入支持 MP3、WAV、M4A、FLAC、OGG、AIFF 等，实际解码能力取决于浏览器。处理采样率取决于浏览器音频上下文；导出可选择 44.1/48 kHz 或当前处理采样率。多于双声道的输入会混合为立体声。

支持波形缩放、毫秒选区、快捷键与窄屏布局。历史最多 60 步，内存紧张时会减少较早的记录。右上角键盘按钮可查看快捷键。默认演示音频在本地合成。

拉伸使用本地打包的 [Signalsmith Stretch](https://github.com/Signalsmith-Audio/signalsmith-stretch)，MIT 许可证与来源信息位于 dist/vendor。均衡器公式参考 [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)。Silkscreen 字体使用 SIL Open Font License，许可证位于 dist/fonts。
