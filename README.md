# Mossroom Studio

棕绿复古像素风格的浏览器音频编辑器。导入、剪辑、调音和导出均在本机完成，音频不会上传服务器。无需安装前端依赖，可离线使用。

## 使用

下载仓库并解压，直接用现代浏览器打开 `dist/index.html`。macOS 也可双击根目录的 `打开 Mossroom Studio.command`。

支持情况取决于浏览器的音频解码能力，建议使用新版 Safari、Chrome 或 Edge。

## 功能

- 多文件资料库、波形选区、毫秒时间输入与缩放。
- 选区播放、循环、试听变速和独立监听音量。
- 保持音高的局部拉伸，支持原时长的 25% 至 400%。
- 任意位置插入静音，后续内容自动移动。
- 低切、高切、三段 EQ、压缩器和噪声门。
- 混响、反馈延迟、声像、立体声宽度、单声道和峰值限制器。
- 输出增益、淡入淡出、峰值标准化、电平与削波指示。
- 调音预设、原音对比、撤销重做、快捷键及调音台教程。
- 完整音频或选区导出，支持 PCM WAV 16 / 24 bit 与采样率转换。

详细操作和限制见 [使用说明](docs/使用说明.md)。网页右上角的“教程”解释各调音功能对声音的影响。

## 本地预览与测试

网页本身无需构建。测试需 Node.js 18 或更新版本；以下预览命令另需 Python 3。

```sh
npm test
npm run preview
```

预览地址为 http://127.0.0.1:8765。也可使用任意静态服务器提供 `dist/`。

## 项目结构

```text
dist/
  index.html            页面与教程
  style.css             复古调音台样式
  app.js                界面、播放、历史与导出流程
  audio-core.js         时间线编辑与 WAV 编码
  mixer-core.js         调音 DSP
  stretch-engine.js     保持音高的拉伸处理
  vendor/               拉伸引擎及许可证
  fonts/                本地字体及许可证
tests/                  音频、时间线与调音测试
docs/                   使用说明
```

使用原生 HTML、CSS、JavaScript 与 Web Audio API。拉伸和 WAV 编码优先使用后台 Worker；音频处理结果在试听与导出之间保持一致。所有依赖资源随仓库打包，不使用外部 CDN。

## 限制

刷新或关闭页面会清除内存中的编辑，请及时导出。原始文件不会改写。单文件上限 100 MB，已解码资料库内存上限 384 MB。较长音频处理可能需要等待。

混响与延迟不会自动增加文件时长，保留尾音前请在结尾插入空白。限制器控制采样峰值，不提供真峰值或 LUFS 响度标准化。试听变速会改变音调，仅局部拉伸保持音高。
